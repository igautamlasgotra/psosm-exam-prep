# PSOSM Exam Prep

A single-page study guide for the NPTEL course **Privacy and Security in Online Social Media (PSOSM)**.

**Live:** https://psosm-exam-prep.vercel.app

## What's inside

- **Exam ka game plan:** how to approach the exam
- **Quiz Retake:** practice the weekly quiz questions again
- **Quiz Decoder:** the reasoning behind quiz answers
- **Topic Notes:** concise notes for each topic
- **Numericals:** formulas, solved examples and practice problems
- **Mock Test:** a full practice test
- **Last-day Sheet:** quick revision before the exam

## Usage

Everything lives in `index.html`, with no build step. Open it in a browser or use the live link above. It works on mobile too.

## Deployment

Hosted on Vercel and connected to this repo. Every push to `main` redeploys automatically.

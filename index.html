Exam ka game plan

NPTEL ke final exam mein usually quiz jaise hi MCQ, MSQ (ek se zyada sahi option) aur kabhi-kabhi numerical aate hain. Inme se bahut saare questions assignment questions ke concepts ko thoda badal ke poochhe jaate hain. Isliye pehle quiz ke concepts pakke karo, phir lecture ke wo important numbers aur facts yaad karo jo abhi tak quiz mein nahi aaye.

Padhne ka order

  1. Quiz Retake: original quiz week-wise dobara do, aur score dekho ki kahan kamzor ho.
  2. Quiz Decoder: har week ke questions kholo. Har question ka answer, wo kis lecture se aaya, aur uske peeche ka concept diya hai. Trap boxes zaroor padhna.
  3. Numericals: centrality (degree, closeness, betweenness), clustering coefficient, density, PageRank, NDCG, Spearman, Jaccard/edit distance, k-anonymity, precision/recall. Har ek ka formula, solved example aur practice hai.
  4. Topic Notes: lecture-wise high-yield facts, yaani wo numbers aur names jo exam mein MCQ ban sakte hain.
  5. Mock Test: 49 naye questions (MCQ + MSQ + numerical) instant checking ke saath. Score 80%+ aana chahiye.
  6. Last-day Sheet: exam se ek raat pehle sirf ye table dekhna.

Week 1OSM overview, 5 V's, incidents
L1–L5
  • Course ka outcome: OSM par spam, phishing, fraud nodes, identity theft jaisi privacy/security concerns samajhna.
  • Social media ke types: social networks (Facebook, Twitter, LinkedIn), publish (Wikipedia, crowd-sourced), social/virtual games. Naye types: ephemeral (content khud destroy ho jaata hai, jaise Snapchat) aur anonymous (Whisper). Lagbhag 215–220 popular SN services hain.
  • "Online in 60 seconds": Facebook par 2.5M posts (2013) se badhkar ~3.3–3.5M; Twitter par 278,000 se 420,000 tweets; YouTube par 100 hours se 400 hours ka video har minute.
  • 5 V's: Volume, Velocity, Variety, Veracity, aur Value (5th, baad mein add hua).
  • Facebook = bidirectional (friend request accept karni padti hai) aur data graph mein store karta hai. Building blocks: post (text/image/video), likes, comments, shares, pages, groups. Twitter = unidirectional microblog (140 chars): followers/following, tweet, retweet, reply, like (pehle 'favorite' tha), hashtag, mention, trends.
  • LinkedIn = connections; Google+ = circles aur +1; Foursquare = check-in, tip, done, mayor; Pinterest = images + boards (sabse tezi se badhne wala); Periscope = live streaming; Tinder = left/right swipe; Whisper = anonymous (categories: popular, latest, LOL, confessions…).
  • Incidents: 2009 Hudson River plane (@jkrums), pehli baar Twitter crisis management mein use hua · Indian railway station par khoyi bachchi 20 minute mein mili (railway minister ko tag kiya tha) · cyberbullying se suicide · UK riots social media se bigde · Nepal earthquake relief · Egypt revolution · Boston rumours · AP ka compromised verified account ('two explosions in White House') · Chennai floods ka crocodile (Dec 2015) · Hurricane Sandy ka shark · Robin Williams ka fake video · MI6 chief ki wife ki FB photos · logon ki naukri jaana.
  • Tutorials: Ubuntu 14.04 desktop ko VirtualBox mein chalaya; sudo apt-get update; apt-get install python-pip; pip Python packages install karta hai jaise apt-get Ubuntu packages (pip install requests).
Week 2APIs, data formats, Trust and Credibility
L6–L9
  • API = program aur OSM ke beech ka 'tunnel'. Har API par rate limits hoti hain. Data JSON mein aata hai (kuch XML mein).
  • Storage: MySQL (relational, rows/columns), jise phpMyAdmin se dekhte hain. MongoDB (non-relational, document, collections), jise RoboMongo se dekhte hain.
  • Facebook mein har object node hai, connections edges hain, aur har node ki unique numeric ID hai, isliye naam Graph API. Graph API Explorer se browser mein data dekh sakte hain. Access token OAuth se banta hai. Short-lived token jaldi expire hota hai (demo mein 38 min bache the), aur App ID + App Secret se use extend kar sakte hain.
  • Credibility analysis ka pipeline: data collection → characterisation → features → ground truth → model → evaluation. Analysis ke sawaal: who, when, where, what, why, how (why aur how sabse mushkil hain).
  • Boston rumour graph: rumours pehle aur tezi se failte hain, aur true information der se aati hai (~9 hours). Do solutions: true info jaldi laao, rumour ki spread jaldi roko.
  • Hurricane Sandy (22–31 Oct 2012, $75B damage): 1,782,526 tweets, ~1M users, 622,000 tweets with URLs. Ground truth The Guardian ki list se: 10,350 tweets with fake images, 10,215 users.
  • Features: F1 = user features (friends, followers, follower-friend ratio, kitni lists mein, URL, verified, account age) aur F2 = tweet features (length, words, ?, !, happy/sad emoticons). Classifiers: Naive Bayes, Decision Tree, 5-fold cross validation. Decision tree + tweet features = 97.65%. Tweet features user features se behtar the.
  • Boston data: 7.8M tweets, 3.6M users, 3.4M with URLs, 62,000 geotagged (Twitter ke ~1% tweets geotagged hote hain). Data query expansion se collect hua. Top 20 viral tweets: 6 rumours, 7 true, 7 generic. Fake tweets ~76% mobile se. 32,000 naye accounts, unme se 19% suspended. Fake accounts ek closed community the.
  • Annotation: Mechanical Turk, har tweet ≥ 3 annotators, Cronbach's α ≥ 0.7. Result: 30% tweets mein information thi, 17% credible thi, 14% spam tha. Ranking quality NDCG se naapi; tweet + user features ka NDCG sabse achha tha.
  • TweetCred: Chrome extension, score 1–7, 45 features, feedback se model update hota hai. Naye features: swear words, positive/negative emotion words, WOT score, YouTube like/dislike ratio. Top-10 features: chars, unique chars, words, user has location, retweets, tweet ki age, URL, 'via', statuses/followers, friends/followers. Users: emergency responders, firefighters, journalists.

Q42 (6,855 responses): 42% ne kaha "privacy settings specify kar di hain, isliye data secure hai" (galat soch). 19% ko koi concern nahi, 23% concerned hain par phir bhi share karte hain. Week 4Privacy and pictures, re-identification
L15
  • Definitions: Robert Post (Three Concepts of Privacy): "a value so complex…". Westin 1967 (Privacy and Freedom): "claim of individuals… to determine when, how and to what extent information about them is communicated". Saar: privacy = control over information.
  • 4 forms: information, communication, territorial, bodily (CCTV).
  • Photos: 2000 mein 100B photos kheenchi gayi; 2010 mein Facebook par 2.5B photos/month; FB+Insta+Flickr+Snapchat+WhatsApp par mila ke 1.8B/day. pleaserobme.com tweets se pata lagata tha ki tum ghar par nahi ho.
  • Re-identification badhne ke 4 karan: self-disclosure badhna, face recognition ki accuracy badhna, cloud computing, aur re-identification techniques ka behtar hona.
  • Sweeney: medical data + voter list, common fields ZIP + birth date + gender → k-anonymity.
  • Face re-identification study (Acquisti et al.), tool PittPatt (baad mein Google ne khareeda):
    • Exp 1, online–online: Facebook (identified; ~270k profiles, 274k images, 110k faces) vs dating site (unidentified; ~6,000 profiles, ~5,000 faces). 500M+ pairs compare hue, MTurk par 5 Turkers per pair, 1–7 Likert. Highly likely 6.3%, highly likely + likely 10.5%, yaani ~1 in 10 log identify ho gaye.
    • Exp 2, offline–online: campus booth par har participant ki 3 photos, 98 participants, 38% sahi Facebook profile se match hue.
    • Exp 3: public data se SSN predict kiya: 27% logon ke pehle 5 digits, 4 attempts mein.
Week 5Policing and OSM
L16–L18
  • Foursquare se home location nikal sakte hain. Mayor = jisne last 60 days mein venue par sabse zyada check-in kiye. Conferences: WWW, ICWSM, COSN, CSCW.
  • #myNYPD campaign ulta pad gaya (negative photos aayi, phir #myLAPD bhi). India mein popular handles: Bangalore City Police, Delhi Traffic Police. @CPBLR ke 688,000 followers the (Aug 2016). Verified = blue tick. Fake police handles bhi the (jaise 'Delhi Traffic Polize', egg profile wala Hyderabad Police). Lagbhag 80–85 police accounts track kiye gaye.
  • L17 Bangalore City Police FB (2014): 255 posts, ~1,600 comments. Coding: 24 citizen post categories, 2 styles (formal/informal), 4 police responses (acknowledge, reply, follow-up, ignore). Sabse zyada posts neighbourhood concerns ke the, uske baad appreciation. Response time: average 30 hrs, max 211 hrs, min 4 min. Acknowledged 21%, "please lodge complaint" 22%. Information direct vs indirect. Trees: worried / why / need / want.
  • L18 (85 police pages, 2010 – Apr 2015): 47,474 citizen wall posts, 85,408 police posts. 4 research questions: topical, engagement, emotional exchange, cognitive and social orientation. Tools: n-grams, K-means, LIWC, ANEW. Valence = positive/negative, arousal = intensity.
  • Findings: police posts mein 'rules, safety, violations', citizen posts mein 'please take action'. Police-initiated discussions zyada focused, citizen-initiated zyada diverse. Jab police comment karti hai (CPC) to comments 9.49% kam hote hain, kyunki police loop jaldi close kar deti hai. Citizen threads mein negative affect aur anger zyada, aur police aane par anxiety kam. Sabse common pronoun 'I' (self-driven posts).
Week 6eCrimes, link farming intro, SNA tutorial
L19–L21
  • eCrimes: phishing (spear phishing = ek specific group ko target, whaling = CEOs ko). Facebook credentials ab bahut valuable hain. Fake customer-service accounts (bank ko tag kiya to fraudster reply karta hai), fake comments on popular posts, fake live streaming videos (Olympics/cricket), fake discounts (Netflix), fake surveys/contests, fake Foursquare tips, social reputation manipulation (Amazon ne 1,000 logon par fake reviews ke liye case kiya), clickbaiting, hashtag hijacking (Coca-Cola #RoyalBaby, DiGiorno #WhyIStayed), compromised account (AP), impersonation (Kiran Rao), work-from-home scam (Pinterest).
  • Klout score (1–100) online influence naapta hai. Link farming web vs Twitter: web par sirf spammers karte hain; Twitter par legit popular users bhi karte hain, aur reciprocity bhi zyada hai.
  • Spam studies: Suspended accounts in retrospect: 1.1M suspended accounts, 7 months, 1.8B tweets, 80M spam; 77% spam accounts pehle tweet ke ek din ke andar suspend. @spam: 25M URLs mein se 8% malicious, click-through 0.13% (email spam se zyada). Automated activity: 16% active accounts highly automated, 11% browser source spoof karte hain.
  • 2009 ka full Twitter dataset: 54M users, 1.9B links; 379,340 accounts suspended (Aug 2009 – Feb 2011); 41,352 ne blacklisted shortened URL (bit.ly/tinyurl) post kiya. Spam followers 248k; 82% spam followers spam targets ke saath overlap. PageRank mein spammers: top 10k mein 7, top 100k mein 304, top 1M mein 2,131.
  • SNA tutorial (L21): representations: adjacency matrix (n×n, sparse graph mein jagah waste karta hai), GraphML (XML), CSV. Tool twecoll. In-degree / out-degree (self-loop dono mein count hota hai). Centralities: in-degree, out-degree, betweenness, closeness. Community = strongly connected group; modularity = edges ka wo fraction jo group ke andar hai.
Week 7Link farmers, Nudges, Spear phishing, NLTK
L22–L25
  • L22: top 100,000 spam followers ne spammers ke 60% links diye. Top spam followers almost har spammer ko follow back karte hain. Follow-back ki probability in-degree ke saath badhti hai, aur low in-degree wale users reciprocate nahi karte.
  • Top 100k link farmers: 18,826 suspended, 4,768 not found, 76% active, 235 verified; 100 random mein se 86 real. Topics: business, internet marketing, social media. In-degree aur out-degree dono high, ratio ≈ 1. Inhe social capitalists kehte hain.
  • L23: privacy policies padhne mein 244 hours/year lagenge, US national cost $781B. MIT tool: mailing list ke recipients ki photos dikhata tha. Facebook nudges (picture / timer 10s / sentiment): 21 participants, 13 interviews, IRB approval (Institutional Review Board). Metrics: privacy settings changes, cancelled/edited posts, post frequency, topic sensitivity. Timer nudge ke baare mein ek user ne kaha "at times annoying, at times handy".
  • L24: Schneier ke attack types: physical, syntactic (DoS, buffer overflow), semantic (insaan ko target karte hain). Semantic barrier = user ke mental model aur system model ka gap. Types: phishing, context-aware, whaling, vishing (phone), smishing (SMS), social phishing. ILOVEYOU virus. Phishing ka cost $3M+ per 100k-employee organisation. APWG = Anti-Phishing Working Group.
  • Social phishing (Indiana University, April 2005, age 18–24): control 16% vs social 72%. 70% authentications pehle 12 hours mein. Kuch logon ne 80 baar tak login try kiya. Females zyada vulnerable the, aur opposite gender se email aaye to success zyada (M→F 78%, F→M 68%). Freshmen sabse vulnerable. Science dept mein gap sabse zyada (80% vs 0%), technology mein sabse kam. Study par backlash hua (unethical bola gaya). Solutions: education, browser tools, fast takedown, digitally signed emails.
  • NLTK (L25): word_tokenize (punkt package chahiye), .lower(), Counter.most_common, PorterStemmer (course/courses → course, certification → certif), stopwords.words('english'), ngrams(tokens, 2), pos_tag (JJ = adjective). Unicode error aaye to .encode('utf-8').
Week 8Profile linking, Anonymous networks, Gephi
L26–L28

Week 9Foursquare privacy: "We Know Where You Live"
L29–L31
  • India survey (location on FB): 39% ne 'everyone' ke saath share kiya, 33% friends, 12.5% friends-of-friends, 5.7% network, 3.1% customised. Doosre state mein phone switch-off message regional language mein aana: 54% ne ise privacy-invasive maana (44% agree + 10% strongly agree).

N1Degree, in/out-degree, degree centrality
deg(v) = edges ki ginti · C_D(v) = deg(v) / (n − 1) · directed: in = aane wale, out = jaane wale

Solved (G): C ke neighbours A, B, D hain, to deg = 3 aur C_D = 3/4 = 0.75. E ki deg = 1, C_D = 0.25.

Directed rule (L21): Twitter mein A → B ka matlab A follows B. B ki in-degree = followers. Self-loop in-degree mein bhi +1 hota hai aur out-degree mein bhi +1. L21 example: node 2 par 1 → 2 aur 2 → 2 (self loop) aate hain, to in-degree = 2; 2 → 4, 2 → 5 aur self loop jaate hain, to out-degree = 3; total degree = 5.

Practice: Directed edges A→B, A→C, B→C, C→A, D→C. C ki in-degree aur out-degree kya hai? Sabse popular (Twitter sense mein) kaun hai?

C: in = 3 (A, B, D se), out = 1 (A ki taraf). C ke sabse zyada followers hain, isliye wahi sabse popular hai. D ki in-degree 0 hai.

N2Density
Undirected: D = 2m / (n(n−1)) · Directed: D = m / (n(n−1))

Solved (G): n = 5, m = 5 → 2·5 / (5·4) = 10/20 = 0.5.

Practice: Directed graph mein 5 nodes aur 8 edges hain. Density kya hai?

8 / (5·4) = 0.4.

N3Closeness centrality: "sabke paas kaun hai"
C_C(v) = (n − 1) / Σ d(v, u) (har doosre node u tak ki shortest distance ka sum)
  1. D se distances: A = 2 (D–C–A), B = 2, C = 1, E = 1. Sum = 6.
  2. C_C(D) = (5 − 1) / 6 = 0.667.
  3. C ke liye: sum = 1 + 1 + 1 + 2 = 5, isliye C_C = 4/5 = 0.8, jo sabse zyada hai.

Practice: Star graph: 1 centre aur 5 leaves (n = 6). Centre ki closeness aur ek leaf ki closeness?

Centre: sab 1 step door hain, sum = 5, to 5/5 = 1.0. Leaf: centre tak 1, baaki 4 leaves tak 2-2, sum = 1 + 8 = 9, to 5/9 = 0.556.

N4Betweenness centrality: "bridge kaun hai" (W6 Q1 type)
C_B(v) = Σ over pairs (s,t), s≠v≠t, of σ_st(v) / σ_st · Normalised (undirected) = raw / [(n−1)(n−2)/2]

N5Local clustering coefficient (Whisper W8 Q4 ka concept)
C(v) = (v ke neighbours ke beech actual links) / (k(k−1)/2), k = deg(v)

Solved: C ke neighbours A, B, D hain (k = 3), to possible links = 3. Actual links mein sirf A–B hai, yaani 1. C(C) = 1/3 = 0.333. A ke neighbours B, C hain, aur B–C exist karta hai, to 1/1 = 1.0. D ke neighbours C, E hain, C–E nahi hai, to 0.

Average clustering (G) = (1 + 1 + 0.333 + 0 + 0)/5 = 0.467. Note: degree 1 wale node ka C = 0 maana jaata hai.

Whisper ka clustering 0.033 tha, jo Facebook (0.059) aur Twitter (0.048) se kam hai, kyunki strangers aapas mein connect nahi hote.

Possible = 4·3/2 = 6, isliye 2/6 = 0.333.

N7NDCG (W3 Q4)
DCG@k = Σ rel_i / log₂(i + 1), i = 1..k · NDCG = DCG / IDCG (IDCG = relevances ko descending sort karke DCG)

Quiz wala solved (standard formula): ranking ki relevances [2, 2, 0, 1, 1].

  1. log₂ values: log₂2 = 1, log₂3 = 1.585, log₂4 = 2, log₂5 = 2.322, log₂6 = 2.585.
  2. DCG = 2/1 + 2/1.585 + 0/2 + 1/2.322 + 1/2.585 = 2 + 1.262 + 0 + 0.431 + 0.387 = 4.080.
  3. Ideal [2, 2, 1, 1, 0]: IDCG = 2 + 1.262 + 0.5 + 0.431 + 0 = 4.193.
  4. NDCG = 4.080 / 4.193 = 0.973 ≈ 0.975.
Quiz key ka formulaOfficial solution ne DCG = rel₁ + Σi≥2 rel_i / log₂(i) use kiya tha, jisse ~0.96–0.975 aata hai. Dono formulas se closest option 0.975 hi hai. Exam mein jo formula diya ho wahi lagao; agar nahi diya to standard formula lagao aur closest option chuno.

Practice: Relevances [3, 1, 2, 0]. NDCG (standard formula)?

DCG = 3 + 1/1.585 + 2/2 + 0 = 3 + 0.631 + 1 = 4.631. Ideal [3, 2, 1, 0]: 3 + 2/1.585 + 1/2 = 3 + 1.262 + 0.5 = 4.762. NDCG = 0.9725.

N8Cronbach's alpha (inter-annotator reliability)
α = (k / (k − 1)) · (1 − Σσᵢ² / σ_T²) k = annotators/items, σᵢ² = har annotator ka variance, σ_T² = total score ka variance

Solved: 3 annotators ne 5 tweets ko rate kiya: T1 (4, 5, 3), T2 (2, 2, 3), T3 (5, 4, 5), T4 (3, 3, 2), T5 (1, 2, 1).

  1. Har annotator ka sample variance: 2.5, 1.7, 2.2, sum = 6.4.
  2. Har tweet ka total: 12, 7, 14, 8, 4 (mean 9). Inka variance = (9 + 4 + 25 + 1 + 25)/4 = 16.
  3. α = (3/2) · (1 − 6.4/16) = 1.5 · 0.6 = 0.90. Ye ≥ 0.7 hai, isliye agreement reliable hai.

N10Pearson vs Spearman (W9 Q2, Q3)
Spearman (no ties): ρ = 1 − 6Σd² / (n(n² − 1)), d = rank(x) − rank(y)

Solved: x ranks 1, 2, 3, 4, 5; y ranks 2, 1, 4, 3, 5. d = −1, 1, −1, 1, 0, to Σd² = 4. ρ = 1 − 24/(5·24) = 1 − 0.2 = 0.8.

N11Username similarity: Jaccard, edit distance, LCS (L26 profile linking)

Jaccard on bigrams: "ponguru" ke bigrams {po, on, ng, gu, ur, ru} aur "pon_guru" ke {po, on, n_, _g, gu, ur, ru}. Common = po, on, gu, ur, ru = 5; union = 8. J = 0.625.
